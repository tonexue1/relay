# Relay · 定位与记忆价值

> 状态:定位收敛(2026-08-17),给对外、招人、做取舍当尺子用。
> 范围:一句话定位、是/不是、给谁、两条楔子、记忆为什么值得做。
> 非目标:实现细节。记忆引擎见 [memory-engine.md](./memory-engine.md),做梦见 [dream-on-device.md](./dream-on-device.md)。

---

## 0. 一句话定位

**Relay 是一个端优先(edge-first)的 Android Agent 运行时:让 Agent 住在设备里、拥有自己的记忆、只在划算时才上云。**

对标不是 LangGraph / CrewAI(服务端 Python 框架),也不是又一个套壳 App,而是 **OkHttp / Coil 那种位置**——App 开发者 `implementation` 进去的基础库,只不过管的是 agent。

---

## 1. 是什么 / 不是什么

| 是 | 不是 |
|---|---|
| Android 原生的 agent 运行时 / SDK | 一个终端用户 App、一个聊天机器人 |
| 把端和云当成**一个系统**,有明确分工纪律 | "纯端上跑个模型" 或 "纯云端 agent 平台" |
| 把端上**私有记忆当一等公民**(会复利的图谱) | 把记忆当成云端的附属缓存 |
| 分层库:`llm`→`ondevice`→`agent-core`→`orchestra`→`samples` | 一个大而全的黑盒 framework |

诚实边界:我们**不**追"端上能力对标云端"——那是输的仗。我们追的是"**私有图住在设备里,只把划算或端上做不到的理解送上云**"。

---

## 2. 给谁用

Android App 开发者——想要 agent 能力,但在乎**隐私、离线、成本可控**:

- 陪伴 / 助理 / 第二大脑类消费应用
- 医疗、未成年人、企业等**原始数据依法不能出端**的合规场景

---

## 3. 楔子(别人套壳云端抄不走的两点)

不是"能在手机上跑模型"——MediaPipe / AICore / llama.cpp 都能。真正立得住的是两条架构主张:

1. **端云分工纪律做成产品原语**:原文捕获、图谱、检索住在端上;口语理解(抽三元组)上云,峰值问答也上云。"谁该在哪"不是 if-else,是贯穿 `orchestra` 的一等公民。**不**把「夜里 3B 免费做梦」当纪律——真对话抽取 S1 已否。
2. **端上会复利的私有记忆**:别人做"一次推理",我们做**终身只增、离线可查、能改能忘、活得比厂商久**的知识图谱。一致性 × 覆盖 × 隐私 > 峰值 IQ。蒸馏可以上云,图不出租。

---

## 4. 为什么做记忆(越用越聪明)

先钉死一句,免得自欺:**"越用越聪明"变聪明的是系统,不是端侧那个 3B。** 模型权重一个字节都不改,变的是喂给它的**上下文质量**。不是端上微调——那做不到。

在这个前提下,记忆的价值分四个**递进**层次,越往下越是真复利:

| 层 | 聪明 = | 何时有 |
|---|---|---|
| **L1 召回 / 个性化** | 不重复、不跑题、贴着你的历史 | day 1 |
| **L2 连接 / 多跳** | 把两件你没连起来的事连起来(过敏 × 菜谱→警告) | 有图就有 |
| **L3 预计算 / 摊销** | 先蒸馏出结论,查询又快又稳;不保证免费(抽取在云) | 做梦跑起来后 |
| **L4 启发式 / 程序性** | 不只记得你,还记得"怎么帮你才对"(采纳/纠正→反馈边) | 需要反馈信号,最难也最值 |

平铺日志只能"翻到",图能"连起来";硬理解(抽边)可以上云做完,查询取回的是结论不是原始记录再推一遍。L4 接的是"启发式学习":把 采纳/否决/纠正 当反馈边写回图,久了 agent 偏向对**你这个人**历史有效的策略——把"记忆"升级成"经验"。

### 4.1 飞轮

```
用 → 原始日志变多 → 云端抽干净边 → 图更浓
   → 检索更准 → 回答更好(端上 3B 也能打) → 更爱用 ↺
         └─(采纳/纠正)→ 反馈边 → 策略更对 ↺
```

### 4.2 记忆是 3B 的救命稻草

2048 窗口、CPU 慢,单打独斗 3B 就是个弱模型。记忆让它把小窗口**全花在相关事实上**,而不是原始历史。好图谱 + 好检索,能让 3B 打出接近大模型的效果。**这不是附加功能,是 edge-first 定位能否成立的前提。**

### 4.3 让复利"被看见"

复利用户感觉不到等于没有。要有**晨报**("我昨晚学到/连起了这些")+ 对话中主动回忆("我记得你提过…")。"变聪明"的体感和真变聪明一样值钱。

### 4.4 承重墙:记忆也能让你越用越蠢

这不是自动向上的。搞砸就是**负复利**:

- 做梦写错事实 → 错误复利,越攒越歪
- 只进不忘 → 上下文污染,检索被垃圾淹没
- 图很大但检索不准 → 死重量

所以 **confidence / provenance / 衰减遗忘 / 晨报复核不是可选项,是承重墙。** 记忆系统成败,一半在"记",一半在"敢忘、能纠"。

---

## 5. 一句话收尾

**记忆的用处不是"存起来",是把"你的历史"和"什么管用"蒸馏成模型用得起的上下文,让系统可见地、带纠错地变好——模型没变强,但它对你越来越对。**
