## 0. 承重假设(塌了愿景就塌)

按依赖顺序捋:

1. ~~**3B+GBNF 能从真实对话抽出干净三元组**~~ —— **2026-08-18 否决**(合成过、`ex-15-live` 真口语 P/R=0)。抽取改云端,见 **S1c**。
2. **给 3B 注入检索到的记忆,回答真的变好** —— 价值命题。种子上注入 83% vs 基线 17%,**暂过**;记忆模块落地后再用真图复测。
3. **云端能从真对话抽出干净三元组(S1c)** —— 新地基。不过则不做自动做梦,改成用户确认后写入。
4. **不靠 embedding,FTS5+图遍历的召回够用** —— 决定是不是偷偷被 embedding 卡住。
5. **做梦可幂等重跑 / 能从日志重建图** —— 「重做梦」「可溯源」。
6. **出端范围可关** —— 未消费片段 opt-in,不是全量日记默认上传。

**S1c 或 S2 挂了,先别写 memory 生产代码。** S1 端侧失败不否决「越用越聪明」,只否决端上 3B 抽取。

## 1. Spike 卡片

### 已裁定

**S1 · 端侧 3B 抽取质量 — FAIL(真对话)**
- 评测台:[eval/dream](../eval/dream/README.md)。
- 合成种子 + 滤边可过闸;真人对话抽不出 `plans 跳槽/休息`。
- **不再为端侧抽取堆 few-shot / 过滤器。** JNI GBNF(S0)从抽取关键路径拿掉。

**S2 · 记忆注入 — 种子 PASS**(注入组明显赢)。落地后复测。

**S4 · 端上过夜吞吐/热/电 — 降级/取消**
- 「端上免费做梦」不再是定位前提。不必为 3B 夜跑测热。

**S0 · JNI GBNF — 后置**
- 短改写/端上工具格式仍可能用,不挡记忆主线。

### 下一闸

**S1c · 云端抽取质量(新地基)**
- 问题:DeepSeek(或同级)能否从 `ex-15-live` + 种子抽出干净三元组?
- 实验:`python extract_cloud.py` → `python score.py --pred out/extract-cloud.jsonl`。
- 阈值:**live P≥70% 且 R≥50%**,并且抽出 `plans 跳槽` 与 `plans 休息`;全量微平均不低于闸门。种子不脏边爆炸。
- 不过:不做自动做梦,改结构化/人点选写入。
- 成本:0.5–1 天。解锁:memory-android 快路径 + 云 extract + 注入 + 晨报。

### 过 S1c 之后

**S3 · 无 embedding 的召回 + 去重够不够**(同前)。成本:2–3 天。

**S5 · 幂等重建** / **S6 · 矛盾与时间** / **S8 · 端上工具预算**(同前,S8 不挡记忆)。

**S7** 并入 S1c:3B 失败样本上云是否修好,就是 S1c 的 live 条。

## 2. 一眼优先级

| Spike | 验什么 | 挂了意味着 | 序 |
|---|---|---|---|
| **S1c 云端抽取** | 新地基 | 不做自动做梦 | **1** |
| S2 注入增益 | 价值命题 | 「越用越聪明」是假的 | 1(已过种子,落地复测) |
| S3 召回/去重 | 是否被 embedding 卡 | 路线图改 | 2 |
| S5/S6 | 图纪律 | 可边做边定 | 3 |
| S8 工具可靠性 | Pipeline 工具预算 | 不挡记忆 | 4 |
| S0 / S4 | 端上 3B 抽取/夜跑 | **不做** | — |

**节奏:S1c 过了才写 memory 生产代码。** 先别实现端上 3B 做梦管线。
