项目经历

求职方向：客户端开发。两年安卓，最近一个月做鸿蒙。材料按「花时间最多 → 能讲架构 → 垫底补技术栈」排，不按时间倒序硬排。

稳定关系来自记忆图：参与过车管家 / 鸿蒙重构 / 网络 SDK。云端下发卡、Repository 策略仍是 Claim，正文里当经历写，不发明新谓语。

1. 车管家 · 卡片引擎

车机侧应用。核心不是做了多少页面，而是卡片怎么从云端走到车端屏幕上。

职责

  • 卡片引擎：模板、数据、刷新节奏收在同一条管里
  • 云端下发卡片描述，车端按描述动态渲染，避免每个业务方各写一套原生页
  • H5 卡片和原生容器之间走 JSBridge：取车况、跳原生、回传点击

技术

  • Android 容器 + H5
  • JSBridge 约定：方法名、线程、失败回包

可讲的点

面试官若问「为什么不全部原生」，答：业务卡片迭代快、车端发版慢，下发描述比跟版更划算。坑在 Bridge 超时和车端 WebView 内存，需要降级成静态底图，而不是转圈到死。

2. 鸿蒙重构 · Repository 分层

最近一个月。不是从零做产品，是把已有数据访问收成可替换策略，方便本地 / 网络切换。

职责

  • Repository 层：界面只打领域接口，不直接碰网络或磁盘
  • 策略模式：本地缓存、网络拉取、失败回落分成可替换实现
  • 和安卓侧旧代码对齐字段，避免两边各讲各的

可讲的点

一个月写不完「整个鸿蒙」。简历上要写成「完成数据层策略拆分，并在列表场景跑通本地优先」，不要写成「主导鸿蒙架构」。鸿蒙是加分项，安卓两年才是底。

3. 网络 SDK

安卓期间的基础库，排在最后。用来证明 Java 和网络栈，不抢前两个项目的篇幅。

  • Java + Retrofit
  • 统一错误码、重试、日志拦截
  • 给业务模块的是一套调用约定，不是每个页面自己 new OkHttp

怎么说、不怎么说

  • 先说车管家，再鸿蒙，最后 SDK。顺序服务「客户端」这个方向，不是服务时间线。
  • 鸿蒙一个月不要压过两年安卓。对方若只看关键词，把安卓能力写在车管家和 SDK 里。
  • Claim 里的细节（云端下发、策略模式）可以进 STAR 的 Action，不要收成图上的假边。

这一屏在验什么

  • 用户短句进气泡；助手回合是 turn group，不套第二层灰泡。
  • 过程 chip 可点，底栏是 tool log。这是胶水，不是 ui-kit。
  • kv 小，可 inline；table / chart 破泡成中性卡。
  • 能落盘的长文走 file：流里写「已生成 xx.md / xx.html」，点开本屏渲染。不是 pptx。
  • 短 MD 走气泡。长 MD 走原生渲染器。HTML 走沙箱 WebView，都是点开看，不丢到系统浏览器。
  • HTML 吃满本地 WebView：栅格、sticky、backdrop、CSS 动画、conic 环、SVG、:checked 页签、details。不拉 CDN，不跑任意脚本。外网和 eval 仍关。
  • 记忆 capture 吃文本 + summary()，不吃 tool ack，不吃原始 spec JSON。

总览是宿主页，不是 tool ack

  • 入口在对话外：底栏「记忆」或侧栏。Playground 现在那块等宽事实文本，就是这一页该取代的。
  • 数据直读 store：facts(graphId) 铺活边，claims(graphId) 铺经历，unconsumed 只做计数。不调 Agent。
  • 画布是窗口，不是海报。一屏只保证当前焦点 + 一跳能看清。其余在画外，拖、捏、点列表去够。
  • 开页焦点是「用户」。点节点或点三元组 = 相机居中到那个点。复位回用户。
  • 同型太多先收成簇（「技能 ×6」），点开再铺。不在手机上做法导全图。
  • 档位：大约 ≤12 节点可一次性 fit；再多就相机+一跳；50+ 不再布局全图，搜索和列表是主路径，图只画焦点邻域。
  • 「标关系」仍可选。字只给视口里的边，画外的不标。
  • 这些都是本地交互，不回 agent。

封闭集怎么铺进对话

tier 0 · inline
text / markdown + fallback

tier 1 · inline / block
kv · table · card

高频结构化只读。kv 可进气泡；table 必须破泡。不引图表库。

tier 2 · block
chart bar / line / pie

第一个真视觉。数据是 series 和 label，配色走主题。

tier 3 · block / canvas
graph

知识图谱。总览画全量活边；对话里可复用同一 renderer 画一跳。Claim 作脚注。

tier 4
file · markdown / html

已生成 xx.md / xx.html，点开本屏渲染。HTML 是逃生口，沙箱 WebView，v1 关脚本关外网。

和 WorkBuddy 对齐后的边界

过程条、赞踩朗读、来源、侧栏任务，都不进 relay/ui-kit。 引擎只做 WidgetSpec → Compose。Playground 胶水听 ToolExecutionStart： 名字有富渲染就画卡（table / chart / graph），否则画过程行。 memory_query 默认是 chip + 边列表；对话里要画邻域再包 render_graph。 总览不走这条管，宿主自己读库。

先验仍是：工具调用先稳定出现在回合里。图谱总览是另一块：让用户看见库里实际有什么。
